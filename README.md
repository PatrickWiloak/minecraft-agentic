# Minecraft Agentic Builder

AI agents that build Minecraft worlds while you watch.

## Quick Start

### 1. Set up a Minecraft Server

You need a Minecraft Java Edition server (1.20.4) with:
- Online mode OFF (for bot connections)
- Cheats enabled (for `/setblock` commands)

**Quick local server with Docker:**
```bash
docker run -d -p 25565:25565 -e EULA=TRUE -e ONLINE_MODE=FALSE -e ENABLE_COMMAND_BLOCK=TRUE itzg/minecraft-server:java21
```

**Or use a local server:**
- Download from minecraft.net
- Set `online-mode=false` in `server.properties`
- Set `enable-command-block=true`

### 2. Install Dependencies

```bash
npm install
```

### 3. Configure Environment

```bash
cp .env.example .env
# Edit .env with your Anthropic API key
```

### 4. Run the Demo

**Single agent:**
```bash
npm run demo "a medieval castle with towers"
```

**Multi-agent crew (the good stuff):**
```bash
npm run crew "a cozy tavern with outdoor seating"
```

## Multi-Agent Mode

The crew demo spawns 4 specialized bots that collaborate:

| Bot | Role | Handles |
|-----|------|---------|
| **Rocky** | Mason | Stone, bricks, foundations, walls |
| **Woody** | Carpenter | Wood, planks, framing, roofs |
| **Fancy** | Decorator | Torches, furniture, interior details |
| **Bloom** | Landscaper | Gardens, flowers, outdoor beautification |

Each bot has its own personality and chats while building. They coordinate through a shared build plan generated by Claude.

```bash
# Parallel mode (bots work simultaneously - more chaotic, more fun)
npm run crew "wizard tower"

# Sequential mode (one bot at a time - cleaner progression)
npm run crew "wizard tower" --sequential
```

## Interactive Mode

```bash
npm start
```

Then type build prompts:
```
> a cozy cabin with a fireplace
> a japanese pagoda
> a pirate ship
```

## In-Game Commands

Join the server and use chat commands:
- `!build <description>` - Request a build
- `!stop` - Stop current build

## For Content Creation

### Recording Tips

1. Start recording your Minecraft client
2. Join the server, position camera
3. Run `npm run crew "epic dragon statue"`
4. Watch 4 bots collaborate in real-time
5. Speed up footage for time-lapse (4-8x works well)

### Content Ideas

- "I let 4 AI agents build a city for 1 hour"
- "AI construction crew vs impossible build challenge"
- "These bots argue while building a castle"
- "Watching AI agents discover architecture"

### What Makes Good Footage

- Multiple bots working in frame simultaneously
- Chat bubbles showing their "thoughts"
- Dramatic zoom-out reveals at the end
- Mistakes/corrections (authenticity)

## Architecture

```
src/
  bot.js         - Mineflayer bot connection
  builder.js     - Block placement logic
  worker.js      - Individual worker bot with personality
  coordinator.js - Claude plans & assigns work
  crew.js        - Multi-agent orchestration
  agent.js       - Single-agent Claude integration
  index.js       - Interactive CLI
  demo.js        - Single-agent demo
  multi-demo.js  - Multi-agent crew demo
```

## Configuration

```env
# .env
MC_HOST=localhost
MC_PORT=25565
MC_USERNAME=BuilderBot
ANTHROPIC_API_KEY=your-key-here
```
